Span

com.alecdorrington.annotatedtextformat.Span
See theSpan companion object
final case class Span(start: Int, end: Int)

A part of a text, from start up to but excluding end, counted in UTF-16 code units, as both the JVM's and JavaScript's strings count them, and the DOM's ranges too. Where they are equal, it is a point between two characters, as where text is to be inserted.
