The colour that CSS writes as css, as #14b8a6, teal, rgb(20 184 166 / 50%) or var(--critic); or else the colour of the text, currentcolor, if css is not one of those forms.

def parse(css: String): Option[Colour]

The colour that CSS writes as css, if it is one of the forms of a colour: a hex colour; a function of a colour space, as rgb(...) or hsl(...), of its numbers, with units or none; a named colour or a system colour; or a custom property, as var(--name), with a colour to fall back on, if any. Where the browser can say, as by CSS.supports, whatever it takes for a colour is one too, as color-mix(...).
